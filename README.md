# mannorr.com

Home for everything Nifemi Adeniran (MANNORR) makes and leads: music, design, Apologetics Nigeria and The Viral Church.

A single static page (`index.html`), no build step. Pages are views switched by the URL hash:
`#home`, `#about`, `#works`, `#music`, `#design`, `#apologetics`, `#viral-church`, `#work-with-me`.
Fonts: Inter Tight and DM Mono from Google Fonts.
